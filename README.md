**Brisa Caiçara**

Projeto de um site fictício para a pousada Brisa Caiçara, localizada em Ubatuba.

**Sobre o projeto**

O site apresenta informações sobre a pousada, suas acomodações, serviços e alguns pontos turísticos de Ubatuba.

**Tecnologias utilizadas**

HTML
CSS
JavaScript

**Funcionalidades**

Navegação entre as seções do site
Apresentação das acomodações
Cards de pontos turísticos
Formulário de contato
Janela de contato utilizando JavaScript

**Projeto**

Este foi meu primeiro projeto publicado no GitHub, desenvolvido como parte dos meus estudos de desenvolvimento web.
